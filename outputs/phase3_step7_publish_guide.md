# Publishing your website

**The founder publishes the website. This system never publishes, uploads or deploys anything.**

Folder: `phase3_step3_site/` (open `index.html` in a browser to preview it).

## Before publishing

- Read every page section; edit or remove anything marked ASSUMPTION that you cannot support.
- Replace the demo sign-up box with your own sign-up provider; the demo form sends and stores nothing.
- Keep the price and policy placeholders until Phase 4 sets them.

## GitHub Pages

https://pages.github.com/

1. Create a public repository on your own GitHub account.
2. Upload the contents of the phase3_step3_site folder (index.html at the top level).
3. Open Settings > Pages, choose Deploy from a branch, select the main branch and the root folder, Save.
4. Open the address GitHub shows after a minute and check the page.

## Netlify

https://app.netlify.com/drop

1. Sign in to your own Netlify account.
2. Open Netlify Drop and drag the whole site folder onto the page.
3. Open the address Netlify shows and check the page; rename the site in Site settings if you want.
