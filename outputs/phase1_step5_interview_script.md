# phase1_step5_interview_script (mom_test_designer)

## questions

```json
[
  {
    "text": "Tell me about the last time you struggled to track client projects, invoices, and revision rounds. What did you do to manage it?",
    "why": "Reveals how designers currently handle project tracking and whether they find existing methods inadequate."
  },
  {
    "text": "Have you ever used any tools or templates to track client projects, invoices, and revisions? If so, what were they and how did they work for you?",
    "why": "Reveals what tools designers are already using and whether they are effective or not."
  },
  {
    "text": "Have you ever paid for a tool or template that helps with tracking client projects, invoices, and revisions? If so, what was the cost and how did it help you?",
    "why": "Reveals how much designers are willing to pay for such tools and whether they find existing options worth the cost."
  },
  {
    "text": "Tell me about the last time you had to send an invoice to a client. How did you track the status of that invoice and any revisions?",
    "why": "Reveals how designers manage invoicing and revisions in practice and whether they find the process cumbersome."
  },
  {
    "text": "Have you ever used a bilingual tool or template for your work? If so, how did it help you, and what challenges did you face?",
    "why": "Reveals whether designers have used bilingual tools and their experiences with them, which can inform the need for a bilingual solution."
  },
  {
    "text": "Have you ever shared client data with a third party or used a tool that collects client information? If so, what were the consequences?",
    "why": "Reveals whether designers are concerned about data privacy and whether they have experienced issues with data collection."
  }
]
```

## rules

```json
[
  "Ask about specific past events and current behaviors, not opinions or future plans.",
  "Avoid pitching the solution or describing the idea in any question.",
  "Focus on what the customer has already tried and what they have paid for.",
  "Look for commitments such as time, money, or introductions.",
  "Treat compliments as noise and focus on actionable behaviors."
]
```

## avoid_list

```json
[
  "Would you buy...",
  "Do you like...",
  "What do you think about...",
  "What would you do if...",
  "What do you hope to achieve..."
]
```
